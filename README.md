# SumoRobot

4 wheel robot controlled by a raspberry pi pico, programmed to push similar robots off a platform. 

Originally made while working on Teknologiskolen SDU summer camp in Odense Denmark, [sumorobot](https://www.teknologiskolen.dk/sumorobot/)
